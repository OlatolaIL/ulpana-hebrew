## 3. Проверенное поведение и негативные мутационные тесты

### 3.1. Интерактивный сценарий жизненного цикла (Уроки 2 и 6)
Для реальных упражнений урока 2 (`ex2-9`, сниппет `תֵּה`, дистракторы `вода`, `кофе`, `молоко`, правильный `чай`) и урока 6 (`ex6-9`, сниппет `אָחוֹת`, дистракторы `семья`, `мама, мать`, `папа, отец`, правильный `сестра; медсестра`) протестирована полная цепочка взаимодействий:
1. **Начальный экран (до ответа):** заголовок содержит нейтральную инструкцию `Послушайте аудиозапись и выберите верный перевод:`, ивритское слово строго скрыто.
2. **Клик по кнопке воспроизведения аудио:** шпион перехватывает вызов `speakHebrew` и подтверждает передачу точного слова (`תֵּה` для урока 2, `אָחוֹת` для урока 6).
3. **Пропуск и возврат:** клик по кнопке «Пропустить» переводит на следующее задание; возврат через «Предыдущий вопрос» возвращает к аудированию — проверяемое слово остаётся строго скрытым.
4. **Неверный ответ:** клик по кнопке с ошибочным вариантом (`вода` / `семья`) переводит упражнение в режим разбора ошибки:
   - В заголовке вопроса раскрывается ивритское слово для анализа;
   - Появляется кнопка «Попробовать ещё раз».
5. **Повтор задания:** клик по кнопке «Попробовать ещё раз» сбрасывает состояние ответа — заголовок немедленно снова скрывает ивритское слово за нейтральной инструкцией.
6. **Правильный ответ:** клик по правильному варианту (`чай` / `сестра; медсестра`) отображает подтверждение успеха (`Верно! Отличный ответ.`) и раскрывает ивритское слово в заголовке.
