## Результат и границы

1. В общем компоненте пользователь должен видеть и выбирать каждый предлагаемый вариант; нажатие вставляет выбранный ивритский текст в текущую позицию курсора по существующему механизму. Не выбирать пол автоматически для всех слов: это может быть род описываемого человека/предмета, а не автора.
2. Простые подсказки без `/` сохраняют прежнее поведение. Предложить понятный компактный способ показать варианты рядом с общей подписью. Не вводить новый сложный экран, обязательный выбор настроек или массовую миграцию данных.
