## Критерии приёмки

- На боевом домене создание сессии отвечает HTTP 200 с ожидаемой схемой и ссылкой на правильного бота; секреты/одноразовые токены в отчёт не включаются.
- GET с отсутствующим или некорректным токеном отклоняется; успех создания не подменяет вход пользователя.
- Вебхук без требуемого секретного заголовка отклоняется, а не становится публично доверенным.
- С тестовым аккаунтом проверен фактический путь: кнопка сайта → Telegram → подтверждение → возврат на сайт → авторизованная сессия → доступ к уроку после гостевого лимита → сохранение входа после обновления страницы.
- Повторное использование/истечение одноразовой ссылки не создаёт чужой или повторной авторизации. Проверка не затрагивает чужие данные и не рассылает сообщения другим людям.
- Если для полного входа необходим один шаг пользователя в Telegram, явно обозначить границу: серверная часть проверена, сквозной вход ожидает этого шага. Не выдавать его за выполненный.
- Определены точная причина, минимальное исправление, активный деплой после изменения и безопасный способ отменить именно это изменение. Не откатывать произвольно последнюю чужую работу.
