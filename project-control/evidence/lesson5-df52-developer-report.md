3. **Pealim — שֶׁקֶל / שְׁקָלִים** (https://www.pealim.com/ru/dict/102-shekel/):
   - `שֶׁקֶל` (шэ́кель), мн. ч. `שְׁקָלִים` (шкалӣм), мужской род. Подтверждает нормативность `עֲשָׂרָה שְׁקָלִים`.
4. **Pealim — שְׁמוֹנֶה** (https://www.pealim.com/ru/dict/7126-shmone/):
