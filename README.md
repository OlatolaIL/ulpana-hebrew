# Ульпана • Курс иврита (100 уроков: Алеф и Бет)

Интерактивное веб-приложение для изучения иврита по методике классического израильского ульпана.

## Возможности
- 100 уроков: Уровень Алеф (1-50) и Уровень Бет (51-100)
- Бесплатный ИИ диалог (Groq Llama 3.3 70B & Gemini 2.0 Flash)
- Словарный разбор по клику на любое слово
- Карточки с интервальным повторением (SM-2)
- Озвучка и распознавание речи
