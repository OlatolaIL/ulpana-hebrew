Каждая сцена собрана по единому проверенному стандарту Фабрики-500:
1. **Шапка бренда:** Логотип `א`, название «Ульпан Алеф», слоган «Иврит без паники», статус записи `● LIVE`.
2. **Вкладки приложения:** `Словарь`, `Диалог`, `Звонок` (соответствует реальному UI Ульпана).
3. **Хук (Сцена 1):** Локация, время, аватар персонажа, карточка контекста.
4. **Факап (Сцена 2):** Дрожащая карточка с ошибкой, реплики с никудом и переводом, радар паники.
5. **Разбор Ульпана (Сцена 3):** Тренажер речи, клик виртуального пальца, синяя звуковая волна, оценка 98%.
6. **Outro (Сцена 4):** Плашка с промокодом (Pop-in Bounce через 3.6 сек после старта CTA), Neon Shockwave пульсация и Shimmer-блик.

### Этап В: Запись через Playwright и кодирование FFmpeg
1. Playwright запускает headless Chromium в разрешении 390×844 с `deviceScaleFactor: 2` (результирующее полотно 780×1688).
2. Загружается `file://.../index.html`, вызывается `window.startReelsTimeline(timings, platformCode)`.
3. Записывается сырой `.webm`.
4. Скрипт сшивает аудиоклипы с **15 мс косинусным кроссфейдом (declick)** в `master.wav`.
5. FFmpeg объединяет видео и мастер-аудио в финальный MP4:
```bash
ffmpeg -y -i raw.webm -i master.wav -vf scale=780:1688:flags=lanczos \
  -c:v libx264 -preset fast -crf 19 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -shortest -movflags +faststart \
  public/demo/lessons/lesson_02_clean_youtube_shorts.mp4
```

## ☁️ 5. Протокол хостинга, CDN и реестров (БЕЗ MP4 В GIT!)

> 🔴 **КРИТИЧЕСКИЙ ЗАКОН R-14 / R-25:**
> Пуш бинарных MP4-файлов (40 видео ≈ 300 МБ) в Git репозиторий **ЗАПРЕЩЕН НАВСЕГДА**. Это приводит к обрывам `curl 55`, превышению буфера GitHub и срыву продакшн-деплоя.

1. **Загрузка в GitHub Releases CDN:**
   * Все 40 MP4 загружаются через скрипт `growth/scripts/upload_release_assets.mjs` в GitHub Release `v-media-lessons-02-05`.
   * Полученные постоянные HTTPS ссылки вида:  
     `https://github.com/OlatolaIL/ulpana-hebrew/releases/download/v-media-lessons-02-05/lesson_02_clean_youtube_shorts.mp4`  
     вносятся в реестр публикаций.

2. **Обновление реестров метаданных:**
   * `growth/lessons_video_registry.json` — метаданные видео (длительность, битрейт, размер, даты).
   * `growth/data/publications.json` — 40 кампаний со всеми UTM-параметрами, текстами описаний, хэштегами и CDN-ссылками.

3. **Синхронизация в память Next.js:**
   * Запуск компилятора:
     ```bash
     node scripts/sync_marketing_publications_ts.cjs
     ```
   * Обновляется файл `src/data/marketingPublicationsData.ts`, обеспечивая мгновенную отдачу админке без чтения файловой системы на Vercel.
