## 1. Архитектура Производственной Фабрики

Производственная фабрика (`growth/scripts/factory_engine.mjs`) — это полностью автономный конвейер генерации кроссплатформенного мультимедийного контента для проекта «Ульпан Алеф».

### 1.1. Соблюдение ключевых правил проекта
- **`R-25` (Только нативный Gemini TTS):** В видео используется исключительно Google Gemini TTS (`Aoede` для женского голоса, `Charon` для мужского голоса). Microsoft Edge TTS категорически исключён из видеопроизводства.
- **`R-27` (Zero-Waste Quota Policy):** Кэширование аудиодорожек в `public/audio/factory/<id>_p<n>.mp3`. Повторные API-запросы к Gemini на готовые фразы заблокированы, что защищает суточный лимит Google AI Studio.
- **`R-28` (Однородность модели и Anti-Click):** Сценарий озвучивается единой моделью. Обработка звука через FFmpeg с 50ms fade-in, 80ms fade-out и обрезкой цифрового артефакта водяного знака SynthID.
- **`R-04` & `R-06` (Современный ктив мале с огласовками):** Все фразы проверены на соответствие современному стандарту Академии языка иврит (без усечённых форм).
- **`R-23` (Изоляция Growth Engine):** Все маркетинговые скрипты и выходные материалы изолированы в каталоге `growth/`, не загрязняя сборку Next.js.
- **`R-16` (Безопасность):** Токены Meta Graph API и Telegram Bot API хранятся исключительно в `.env.local`.

## 2. Структура медиа-пакета кампании

Для каждой из 20 тем фабрика генерирует изолированный пакет в `growth/output/campaigns/<scenario_id>/`:
1. `video_square_1080x1080.mp4` — Мастер-видео 1:1 для Facebook и Telegram.
2. `video_vertical_1080x1920.mp4` — Мастер-видео 9:16 для YouTube Shorts, Instagram Reels и TikTok (с безопасными полями 140px сверху и 220px снизу).
3. `slides_square/slide_1.png..slide_5.png` — 5 слайдов 1080x1080 высокого разрешения (для Instagram Карусели).
4. `slides_vertical/slide_1.png..slide_5.png` — 5 слайдов 1080x1920 для вертикального сторис-формата.
5. `post_facebook.txt` — Копирайтинг для Facebook с разметкой Zero-Link.
6. `post_telegram.html` — HTML-пост для Telegram с тегами `<code>`, `<b>` и ссылкой с промокодом `TG`.
7. `post_instagram.txt` — Копирайтинг для карусели/Reels с триггером в комментарии «ИВРИТ» и промокодом `INSTA`.
8. `post_youtube_shorts.txt` — SEO-текст для Shorts с таймкодами (0:00, 0:03, 0:08...) и ссылкой на тренажёр.

## 4. Специфика дистрибуции по социальным сетям

### 📘 1. Facebook (Страница «Ulpana - Иврит без паники», ID: 1261423050393637)
- **Формат:** Квадратное видео 1:1 (`video_square_1080x1080.mp4`).
- **Алгоритмический протокол Zero-Link:** Ссылки внутри тела поста пессимизируют охват на 70-80%. Текст поста публикуется полностью чистым от ссылок, а прямая ссылка на тренажёр публикуется первым комментарием от имени страницы через Meta Graph API.
- **Промокод:** `FB_POST` (30 дней бесплатного премиума).

### ✈️ 2. Telegram (Канал @ulpana_il)
- **Формат:** Квадратное видео 1:1 через нативный метод `sendVideo` с флагом `supports_streaming=true`.
- **Контент:** Пост в HTML-разметке с акцентом на произношение и моноширинным ивритом (`<code>`), плюс инлайн-кнопка под видео: `👉 Начать практику (промокод TG)`.
- **Промокод:** `TG`.

### 📸 3. Instagram (Бизнес-аккаунт @ulpana_alef)
- **Формат 1 (Основной ленточный):** Карусель из 5 слайдов 1:1 (`slides_square/slide_1.png` .. `slide_5.png`). Карусели дают максимальный процент сохранений (Save Rate) и репостов.
- **Формат 2 (Reels):** Вертикальное видео 9:16 (`video_vertical_1080x1920.mp4`).
- **Лид-магнит:** Ссылка в описании профиля (Bio) + автоматизация директа: призыв «Напишите *ИВРИТ* в комментариях, и бот пришлёт ссылку в личные сообщения».
- **Промокод:** `INSTA`.

### 🔴 4. YouTube Shorts (@ulpana_alef)
- **Формат:** 9:16 вертикальное видео (`video_vertical_1080x1920.mp4`).
- **SEO-оптимизация:** В описании прописаны точные таймкоды для глав плеера, теги `#shorts #иврит #ульпан #израиль` и закреплённый комментарий с реферальной ссылкой.
- **Промокод:** `YOUTUBE`.

### 🎵 5. TikTok (@ulpana_alef)
- **Формат:** 9:16 вертикальное видео (`video_vertical_1080x1920.mp4`).
- **Динамика:** Яркий бейдж и визуальный анализатор звуковой волны удерживают внимание зрителя с 1-й секунды.
- **Промокод:** `TIKTOK`.

## 5. Консольные команды управления

### Сборка кампаний:
```bash
# Сборка одной кампании (проверка и компиляция):
node growth/scripts/factory_engine.mjs --id=sc-01-kindergarten

# Пакетная сборка всех 20 кампаний:
node growth/scripts/factory_engine.mjs --id=all
```

### Автопостинг и валидация:
```bash
# Предпросмотр (dry-run):
node growth/scripts/factory_publisher.cjs --id=sc-01-kindergarten

# Боевая публикация в Facebook и Telegram:
node growth/scripts/factory_publisher.cjs --id=sc-01-kindergarten --send

# Публикация только в Facebook:
node growth/scripts/factory_publisher.cjs --id=sc-01-kindergarten --network=facebook --send

# Публикация только в Telegram:
node growth/scripts/factory_publisher.cjs --id=sc-01-kindergarten --network=telegram --send
```
