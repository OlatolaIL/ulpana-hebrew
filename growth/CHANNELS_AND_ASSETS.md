> **Механизм авто-захвата промокодов (Deep Referral Capture):**
> 1. Все промокоды (`FB`, `INSTA`, `LATTE`, `MOMS` и др.) создаются и настраиваются **динамически** в админке `/admin` во вкладке «Промокоды».
> 2. При переходе пользователя по ссылке вида `https://ulpana-hebrew.vercel.app/?promo=FB` (или `?ref=FB`):
>    - Промокод захватывается и сохраняется в `localStorage` (`ulpana_pending_promo`).
>    - Адресная строка автоматически очищается через `replaceState`, сохраняя чистый URL для пользователя.
>    - Пользователь видит всплывающее подтверждение: *«🎁 Промокод FB зафиксирован!»*.
>    - Промокод автоматически подставляется в окно подписки и фиксируется за профилем.
> 3. В админке `/admin` для каждого промокода доступна кнопка копирования готовой ссылки в 1 клик.

## 🔑 3. Карта переменных окружения (.env mapping)

Для работы маркетинговой автоматизации используются следующие ключи:

| Переменная окружения | Назначение | Где задается |
| :--- | :--- | :--- |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота для проверки подписки и автопостинга | `.env.local` / Vercel Env |
| `TELEGRAM_ADMIN_CHAT_ID` | Ваш личный ID в Telegram для получения алертов о лидах | `.env.local` |
| `NEXT_PUBLIC_APP_URL` | Базовый URL приложения для генерации реферальных ссылок | `.env.local` |
