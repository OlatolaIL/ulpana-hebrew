# Паспорт механики: Пользовательские настройки и аудиосистема

> **Назначение документа:** Единственный источник истины (SSOT) для соблюдения пользовательских настроек профиля (`UserProfile`), работы синтеза речи (TTS), согласования по роду и реестров студийного аудио в платформе «Ульпан Алеф».  
> Паспорт детализирует Блок 7 Матрицы решений (`DECISION_MATRIX.md`), правила **R-17**, **R-24**.

---

## 🎯 Учебная и продуктовая цель

Гарантировать персонализированное, акустически достоверное и методически выверенное восприятие иврита на слух и визуально. Исключить ситуации, когда пользовательские предпочтения (скорость речи, огласовки, род) молча игнорируются кодом, а также предотвратить искажения ударения в сленговых и заимствованных словах.

---

## 🛡️ Обязательные инварианты

### U-01. Обязательное чтение настроек профиля (R-17)
* **Уровень:** 🔴 `BLOCKING`
* **Правило:** Все компоненты, хуки и API-роуты, отображающие иврит или воспроизводящие звук, **обязаны** использовать актуальные параметры объекта `UserProfile`:
  1. `gender` (`'male' | 'female'`):
     - Динамическая адаптация грамматических форм 1-го и 2-го лица (`adaptSentenceForGender`: глаголы, местоимения, огласовки, транскрипция).
     - Выбор целевого голоса синтеза/записи (мужской или женский).
  2. `showNikkud` (`boolean`):
     - Отображение текста с огласовками либо вызов `stripNikkud()` при `showNikkud === false`.
     - Запрещён хардкод иврита с неудаляемыми огласовками или без огласовок вопреки настройке.
  3. `showTranscription` (`boolean`):
     - Показ либо скрытие вспомогательной кириллической транскрипции.
  4. `fontStyle` (`'print' | 'cursive'`):
     - Применение CSS-классов шрифта (`font-print` vs `font-cursive`).
  5. `speechRate` (`number`):
     - Передача скорости речи в `speakHebrew({ rate: userProfile.speechRate })`.
     - Стандартный резервный fallback при отсутствии настройки: строго **`0.7`** (учебный замедленный темп).
     - **Запрет:** Вызов `speakHebrew` без передачи параметра `rate` из профиля является нарушением R-17.

### U-02. Двухголосый нейросетевой комплекс для предложений курса
* **Уровень:** 🔴 `BLOCKING`
* **Архитектура голосов:**
  - Канонический комплекс Gemini 3.8 Flash-Lite TTS: мужской голос **`Orus`** (♂), женский голос **`Aoede`** (♀).
  - Резервный комплекс Microsoft Edge Neural TTS:
    - Мужской: `he-IL-AvriNeural` (ключ в манифесте: `manifest[key]`).
    - Женский: `he-IL-HilaNeural` (ключ в манифесте: `manifest[key::female]`).
  - Голоса участников диалогов обязаны быть контрастными и не сливаться.

### U-03. Реестр эталонного студийного аудио Curated Studio Audio (R-24)
* **Уровень:** 🔴 `BLOCKING`
* **Правило:** Слова и выражения с нерегулярным, пенультимативным (на предпоследний слог) или нестандартным ударением (сленг, заимствования, акронимы) не озвучиваются через стандартный браузерный TTS.
* **Слова реестра:**
  - `סַבָּבָה` (саба́ба), `תַּכְלֶס` (та́хлес), `פְרָאיֶיר` (фра́ер), `סַחְבָּק` (са́хбак), `פַּנְצֶ'ר` (па́нчер), `צִימֶר` (ци́мер), `טַאבּוּ` (та́бу), `סִילָבּוּס` (си́лабус), `צַהַ"ל` (ца́hаль), `בָּאסָה` (ба́са), `יָאלָּה` (я́лла).
* **Техническая реализация:**
  - В `src/lib/speech.ts` действуют константные реестры:
    - `CURATED_STUDIO_AUDIO`: маппинг слов на `/audio/words/*.mp3`;
    - `CURATED_SENTENCE_AUDIO`: маппинг фраз на `/audio/sentences/*.mp3`.
  - При воспроизведении сначала проверяется наличие в реестре; при совпадении воспроизводится HTML5 Audio, браузерный Web Speech API не вызывается.
  - Пополнение новыми словами производится скриптом `scripts/fetch_curated_audio.cjs` с обязательной валидацией акустического RMS-профиля (пик энергии строго на ударном слоге).

## ⛔ Отменённые подходы (Superseded Anti-Patterns)

1. **`speechSynthesis.speak()` внутри `setTimeout`:** Уничтожает браузерный контекст User Activation на мобильных устройствах (iOS Safari / Android), приводя к полной тишине. Вызов TTS строго синхронен клику.
2. **Склейка слогов («Франкенштейн»):** Попытка собрать словарное слово из кусков других слов Pealim искажает распределение энергии и ударение.
3. **Разделение слов пробелами (`סַבָּ בָּה`):** Ломает синтаксис предложения и вызывает чтение по слогам с неестественной паузой.
4. **Озвучка единственным женским Google TTS без огласовок:** Приводит к неверному прочтению омографов (например, чтение «ани роца» при мужском поле).
