# Pre-Flight Checklist — «Ульпан Алеф»

> **Этот скилл — обязательный первый шаг перед ЛЮБЫМ ответом или действием (вопрос, аудит, анализ, код).**
> Иерархия: `AGENTS.md` → `DECISION_MATRIX.md` → `docs/mechanics/*.md`

## Шаг 1 — Прочитать матрицу решений

Открой и прочитай файл целиком:

```
c:\Users\azrie\Documents\antigravity\goofy-maxwell\DECISION_MATRIX.md
```

## Шаг 2 — Вывести Intent Radar

После прочтения матрицы **обязательно** вывести блок:

```
## 🎯 Intent Radar

🟢 Активные инварианты:
  - [перечислить правила R-XX, которые затрагивает текущая задача]

🟡 Предупреждения / Advisory:
  - [архитектурные риски или пограничные случаи]

⛔ Отменённые подходы (не повторять!):
  - [Superseded Log: что нельзя делать в текущей задаче]
```

## Шаг 3 — Проверить критические точки по задаче

Перед написанием кода ответить на вопросы:

| Вопрос | Ответ |
|--------|-------|
| Затрагивает ли задача иврит/огласовки? | R-04, R-05, R-17 |
| Используется ли speakHebrew? | R-17: обязателен `{ rate: userProfile.speechRate \|\| 0.7 }` |
| Меняется ли database.ts? | R-02: ЗАПРЕЩЕНО вручную |
| Есть ли секреты/токены в коде? | R-16: BLOCKING |
| Меняется ли механика Этапа 6? | R-15: сверься с `docs/mechanics/stage-06-phone-call.md` |

## Шаг 4 — Только теперь приступать к задаче

После выполнения шагов 1–3 — работать по задаче.

## Шаг 5 — Post-Task аудит

По завершении задачи запустить:
```
npm run audit:intent
```
И ответить на 3 вопроса:
1. Работали по матрице или нет?
2. Сломали что-то или нет? (физический запуск `npm test`)
3. Нужно ли обновить матрицу?
